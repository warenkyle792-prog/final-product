EventTracker — imported source
==============================
This checkout now runs the full application source imported from
github.com/warenkyle792-prog/eventtracker:

  server/   Express + Socket.IO API, SQLite (sql.js) data layer, seed script
  client/   React (Vite) application — every page and component is editable

RUN
  npm ci
  npm run seed     # writes server/data + demo artwork (skips if data exists)
  npm run build    # builds client/dist
  npm start        # API + built client on http://localhost:5000

  npm run dev      # API :5000 and Vite :5173 with hot reload

NOTES

  incompatible API. It remains available in git history on master and in the
  commit preceding this import.

  both are ignored by git and meant to be recreated with npm run seed.
